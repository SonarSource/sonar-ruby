# Reporting Security Issues

Do not report security vulnerabilities in public GitHub issues.

To report a vulnerability in the Ruby analyzer, use [GitHub's private vulnerability reporting](https://github.com/SonarQubeCommunity/sonar-ruby/security/advisories/new): open the repository's **Security** tab and select **Report a vulnerability**. The maintainers will acknowledge your report and work with you on a fix and its disclosure.

For security vulnerabilities found in third-party libraries, please also contact the library's owner or maintainer directly.
