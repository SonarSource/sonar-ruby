# Reporting Security Issues

This policy covers the community-maintained Ruby analyzer at
[SonarQubeCommunity/sonar-ruby](https://github.com/SonarQubeCommunity/sonar-ruby).

Report a suspected vulnerability privately using GitHub's
[Report a vulnerability](https://github.com/SonarQubeCommunity/sonar-ruby/security/advisories/new) form.
Include the affected plugin and SonarQube versions, steps to reproduce, and the potential impact.
Do not disclose vulnerability details in a public issue or pull request.

The repository maintainers handle reports and coordinate fixes and disclosure with the reporter.

For vulnerabilities in SonarSource products, contact
[security@sonarsource.com](mailto:security@sonarsource.com) and follow SonarSource's
[Responsible Vulnerability Disclosure policy](https://community.sonarsource.com/t/responsible-vulnerability-disclosure/9317).

For vulnerabilities in third-party libraries, also contact the library's owner or maintainer privately.
